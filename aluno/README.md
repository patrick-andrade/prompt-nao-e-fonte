# Pacote do aluno

Canal da turma: clone [https://github.com/patrick-andrade/prompt-nao-e-fonte](https://github.com/patrick-andrade/prompt-nao-e-fonte).

Primeira leitura: [`docs/ferramentas.md`](../docs/ferramentas.md) (o que é cada ferramenta e cada extensão de arquivo; três degraus de participação). Em sala, na raiz do clone: `python scripts/validar_contrato.py` — nada a instalar. Para casa: `python scripts/preparar_lab.py` monta o `.venv` para o lab de lacunas.

Lista, o que não abrir antes do slop, e zip opcional: [`docs/pacote-aluno.md`](../docs/pacote-aluno.md).

Fallback sem git: `uv run python scripts/empacotar_aluno.py` → [`minicurso-prompt-nao-e-fonte.zip`](minicurso-prompt-nao-e-fonte.zip) (sem autópsia e sem `aula/`).
